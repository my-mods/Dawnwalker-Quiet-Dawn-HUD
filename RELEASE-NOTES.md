# Quiet Dawn HUD - Auto-hide HUD — development build

Initial implementation for local in-game testing. Not a published release.

Disable HUD Tweaks and HUD Tweaks - Fixes in Vortex, deploy, then import and enable Quiet-Dawn-HUD.zip. Keep the compatible UE4SS loader enabled. F8 toggles manual reveal.

Offline runtime and archive/installer checks are recorded in the development handoff. Gameplay acceptance and actual frame-time measurements remain pending. This mod does not reproduce HUD Tweaks' styling or fade animations.

Optional: choose Quiet-Dawn-HUD-Show-Compass.zip to retain the normal compass while the other five panels auto-hide. Install one version only. Back up configuration before switching; replace the previous entry through Vortex with the game closed.
